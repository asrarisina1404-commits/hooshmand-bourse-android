# هوشمند بورس — نسخه آزمایشی اندروید

این پروژه یک نمونه اولیه Native Android برای غربالگری روزانه نمادهای بورس و فرابورس ایران است.

## قابلیت‌های نسخه اولیه
- دریافت دیده‌بان بازار از endpoint عمومی TSETMC
- دریافت داده حقیقی/حقوقی
- بررسی تاریخچه قیمت و حجم برای حداکثر ۳۵ نماد نقدشونده
- امتیازدهی اولیه و نمایش حداکثر ۵ نماد
- عدم نمایش سیگنال در صورت شکست دریافت داده

## محدودیت‌های مهم
1. APIهای مورد استفاده در این نمونه، endpointهای عمومی و مستندنشده/جامعه‌محور TSETMC هستند و ممکن است تغییر کنند.
2. گزارش‌های توسعه‌دهندگان از محدودیت دسترسی برخی endpointها برای IP خارج از ایران حکایت دارد. در صورت خطای دسترسی، به زیرساخت داده داخل ایران یا ارائه‌دهنده مجاز داده نیاز است.
3. این نسخه برای آزمون فنی است؛ امتیازها توصیه خرید نیستند و هنوز بک‌تست، اعتبارسنجی داده، کنترل توقف نماد، صف، تعدیل قیمت و آزمون خارج از نمونه انجام نشده است.
4. جریان پول با اختلاف حجم خرید و فروش حقیقی ضربدر قیمت پایانی تقریب زده شده است؛ این مقدار معادل دقیق گردش ریالی معاملات حقیقی نیست.
5. برای استفاده واقعی باید قواعد امتیازدهی با داده تاریخی بورس ایران بک‌تست شوند.

## ساخت APK
نیازمند Android Studio و Android SDK (API 35) و JDK 17 است.

1. پوشه پروژه را در Android Studio باز کنید.
2. منتظر Sync شدن Gradle بمانید.
3. از منوی Build گزینه Build APK(s) را انتخاب کنید.
4. فایل خروجی معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

یا در ترمینال:
`gradle assembleDebug`
